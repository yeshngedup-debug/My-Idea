# Design brief — Bhutan Tech Connect

**Summary**: A Bhutanese student–startup matching platform connecting college students with short paid projects from founders.
**Audience**: Bhutanese students (18–25) and startup founders; met on website header, favicon, app icon, social.
**Brand adjectives**: connected, trustworthy, bridging-opportunity, youthful. **Avoid feeling**: corporate-cold, literal clip-art, over-complex.
**Promise / big idea**: "Back people, not companies" — bridging student talent to founder opportunity.
**Competitive landscape**: tech category leans blue, connected-node networks, circle containment, generic circuit lines. Open territory: warm navy + amber, Bhutanese distinctiveness without sacred symbols (no dragon).
**Mark type hypothesis**: Combination mark — symbol + wordmark; symbol must stand alone as favicon/app icon (mark-type decision guide #5).
**Must work on**: favicon (16px), app icon, website header, social avatar, one colour (white on navy, navy on white).
**Constraints**: keep existing landing palette — navy #16324f + amber #fbbf24; no live `<text>`; clean SVG; 256 canvas.
**Success criteria**: recognisable at 16 px; distinct from generic tech logos; reads as "precise but warm."
**Assumptions**: name final; no existing logo equity to preserve; decision-maker is the product owner.

## Addendum — 2026-11-24: resolved canonical palette

The original navy `#16324f` + amber `#fbbf24` direction has been consolidated
into one palette that matches the built UI: **forest `#17352b`** (page `#f5f2ea`,
surface `#fffefa`, ink `#18251f`), **vermilion** (`#b23c26` for small text,
`#d84f37` for warm accents/focus), and **amber `#fbbf24`** (display variant
`#e7b648`, in-app logo arch `#e0ad3c`). Forest replaces navy for contrast on
warm paper; vermilion adds warmth without a cold corporate-blue read. No site
repaint was performed — this is a documentation reconciliation. See
`design/brand-guidelines.md`, `design/brand-system.md` and the typed tokens in
`lib/design-tokens.ts`. The constraint line above is superseded by this table;
the historical navy SVG masters remain as source artifacts only.
